Image preparation help

Resize a photo or signature for an online form

Application portals can check image dimensions, format and file size independently. Start with the current instructions for the exact form you are submitting, then enter those limits in the image preparer.

Find the exact requirements first

Write down the required format, width and height, any minimum or maximum file size, and any crop or background rules. Requirements vary by organization and application cycle. A rule from an older notice or another exam may not match the form in front of you.

FormReady is an independent utility. It does not receive official portal rules or certify that a file will be accepted. Do not treat a preset or an example from another site as current instructions.

Match dimensions and crop ratio

If the portal gives pixel dimensions, use those values directly. If it gives a physical size and a dots-per-inch value, a basic conversion is:

pixels = millimetres ÷ 25.4 × DPI

For example, 25.4 mm at 300 DPI corresponds to 300 pixels. Use that calculation only when the instructions specify both physical size and DPI; a portal that checks pixels may not care about print metadata.

Set the crop to the same width-to-height ratio as the target image. Resizing a square crop into a tall portrait can stretch the image or cut off important areas. Inspect the final crop before saving.

Meet the file-size limit without guessing

Pixel dimensions and file size are separate checks. JPEG quality and image detail affect how many kilobytes a file uses, so the same dimensions can produce different file sizes. Reduce quality gradually, then check the measured output against the portal’s minimum and maximum rather than assuming that “smaller” is always better.

Use the requested format. Changing a filename extension does not convert an image. If the portal accepts only JPEG, make sure the downloaded file is actually JPEG.

Review the saved image

  1. Compare the downloaded dimensions, format and measured file size with the current official requirements.
  2. Open the result and check that the face or signature is clear and not stretched.
  3. Keep the original image so you can retry with a different crop or quality setting.
  4. Upload the result to the official portal and follow its own validation messages.

The image is processed in your browser and is not uploaded to FormReady. That protects the local workflow, but only the application portal can decide whether a submitted file meets its rules.

Common photo and signature resize questions

Can I resize a photo to a required KB range?

Yes. Enter both the minimum and maximum file size from your current instructions. FormReady searches JPEG quality settings and checks the exported bytes. Some images cannot reach a requested range at fixed dimensions; when that happens, the checker reports that it needs attention instead of padding the file or claiming success.

How do I make a signature image with a white background?

Upload a clear scan, choose Signature, and turn on Clean signature background. It whitens light paper and increases contrast for darker ink. Inspect the result carefully because thin strokes, coloured ink or uneven lighting may need a different scan or manual editing.

Are exam presets current, and does a green check mean accepted?

Requirements change by exam and application cycle. Presets show their official source and cycle; entries marked historical are only a reference. Enter the current notice values if a preset does not match. A pass means the measured file properties match the values entered; it does not verify identity, image clarity, signature authenticity or portal acceptance.

Should I add my name and date to a photo?

Only when the instructions for the application you are submitting explicitly ask for it. The name and date strip is optional and starts off.
