          Existing text edits are written to supported PDF text content and keep the original font and position. Replacement characters must exist in the PDF font, and the new text must fit the original line width. Scanned pages and unsupported fonts or layouts need OCR; OCR replacement covers the old text with a mask and approximates its font and spacing. A blacked-out page is flattened, removing covered text from search and copy; this can change appearance and increase file size. OCR can be inaccurate: check every region. This visual redaction is not a substitute for legal or forensic document review. Password-protected files are not supported. Save a copy before using the result for important documents.

          A focused set of PDF tools

          Add text, highlights, rectangles, images and a hand-drawn signature; move or remove added items; reorder or delete pages; and save a new PDF. Extract selectable text from every page or use on-device OCR on scanned pages. The direct text editor can replace or delete supported existing text in place. It supports standard Type 1 fonts, embedded Type 1 subset fonts with Unicode maps, and embedded Type 0 Identity-H CID fonts. It can join consecutive same-style runs, including some PDFs that draw text one character at a time, while preserving selectable text and the line position. Replacement characters must exist in the source font and fit within the original line width. Scans, vertical/custom font encodings, unusual text transforms and unsupported layouts may still need OCR or another editor. For combining separate files, use Merge PDF.

          Document previews and edits run locally in this browser. OCR downloads its worker and English model from jsDelivr. Direct text editing downloads a qpdf WebAssembly engine from this site. Your PDF is not uploaded to QuickKit.
