About QuickKit

QuickKit is a small collection of free, account-free utilities for common file and text tasks.

Compress an image to a measured size, merge PDFs, clean and count text, generate a password, or create a Wi-Fi QR code. These tools run in your browser so the file and text workflows do not need an upload service.

Output support depends on your device and browser. Check a download before using it in a high-stakes workflow.
